# 拍摄数据与数据工具的信息架构

## 页面职责

`/photo-data` 专注统计分析；逐文件检索移至 `/data-tools` 的「照片明细」，普通进入数据工具时默认折叠。

| 区域 | 功能 | 使用方式 |
|---|---|---|
| 拍摄数据操作区 | 扫描模式、启动与取消扫描、只读来源、索引状态 | 扫描完成后详情默认收起；扫描进行中或出错时展开 |
| 统计筛选工具栏 | 当前范围、筛选摘要、全局筛选、明细入口 | 图表选择更新当前统计筛选；明细入口将完整条件带至数据工具并展开 |
| 拍摄数据分析 | 总览、器材与组合、曝光与焦距、拍摄时间、文件与质量 | 仅请求聚合数据，不加载文件行 |
| 数据工具：照片明细 | 文件分页、路径搜索、元数据详情、导出 | 首次展开才加载；同页收起再展开保留筛选、搜索与分页 |
| 数据工具：数据库维护与 GGPack | 照片索引维护、设备库与心愿池导入导出 | 与照片明细分别管理 |

## 筛选与路由

- 两个页面复用 `PhotoDataWorkspace` 的筛选、预设和导出逻辑，分别以 charts / files 模式运行。
- 「查看照片明细」使用 `/data-tools?photo_files=1&photo_filter=...`。`photo_filter` 携带版本化 `photo-filter.v1` AST，保留嵌套 AND/OR/NOT 条件；非法结构回退为空条件。
- 旧入口 `/photo-data?view=files` 自动重定向至数据工具，保留 `camera`、`lens` 等已有参数。普通 `/data-tools` 入口不自动展开明细。
- 明细路径搜索追加 `files.relpath contains` 条件，仅作用于文件分页、匹配数量和明细导出，不改变图表统计范围或全局筛选预设。
- 全局条件、每页条数或搜索文本改变时分页归零；搜索采用 240ms 防抖。元数据列 Facet 仅在打开筛选并切换到该模式时请求。
- 全局筛选使用 document.body Portal 的宽幅模态窗口，内部独立滚动；支持 Escape、Tab 焦点循环和关闭后焦点恢复。文件元数据窗口也使用 Portal 并支持 Escape 和焦点恢复。
- 顶栏和概览页「正在感受」链接至 `/archive?feeling_only=true`，口径与统计一致：所有 `score = -1` 的设备，不额外限定持有状态。档案筛选保存在 URL，打开和关闭设备详情保留条件。

## 图表呈现

- 器材页依次显示机身榜、镜头榜、组合榜、年度机身更替、品牌占比和机身镜头矩阵。
- 器材榜按拍摄次数降序显示序号、可读名称、次数和占当前拍摄总量的比例；未记录信息独立列出。点击仍使用原始规范化键筛选。
- 年度机身更替使用堆叠柱形图；同一机身在榜单与年度图中保持相同颜色，图例只保留一组。
- 月份按时间升序展示，默认最近 24 个月，可切换最近 12 个月和全部历史。时间图提供键盘可用的数值筛选入口；小时和星期保留自然顺序。
- 焦距与 ISO 使用未分桶的逐值折线图；光圈、快门和曝光补偿按档位柱图呈现，只合并标准档位附近的表示偏差，保留原始索引值与精确筛选口径。
- 矩阵使用整行宽度和更宽标签；明细中的光圈、焦距按展示精度格式化，原始索引数值不变。

## 数据与维护边界

- 打开页面、筛选和查看明细仅查询 SQLite 索引，不扫描照片原件，不分析 GPS 或图片像素。物理文件与逻辑拍摄分别计数，RAW+JPEG 配对规则不变。
- 扫描仍需手动启动，大规模移除仍需确认 NAS 挂载完整。旧索引迁移仍可选择稍后升级，不自动执行破坏性迁移。
- 数据工具展示数据库容量、空闲页与旧版备份体积；P1 失效索引清理和 VACUUM 需在无扫描时手动执行。旧版备份不自动删除。
