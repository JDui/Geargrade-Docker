# 拍摄数据（Photo Data）设计规范

> 文档状态：设计基线 v1.1（2026-10-09），尚未实施。目标仓库：Geargrade-Docker，目标主分支：main。
> 本目录仅是规范；不能将文档中的页面、接口、格式兼容或性能目标理解为现有已实现功能。

## 1. 产品定位与约束

Geargrade 保持“摄影器材档案库”定位，在顶栏追加独立“拍摄数据”标签页（/photo-data）。它是一套**只索引照片文件元数据、不接管照片文件本身**的拍摄行为分析系统：通过历史文件还原真实的摄影器材使用习惯、拍摄技术偏好、时间线、文件体量与拍摄量变化。

必须同时满足：

1. **手动触发**：唯一能够触碰已配置扫描目录的常规动作是用户点击“扫描更新”并发出 POST /scan。添加路径、加载页面、读取上次扫描时间、浏览统计、导出索引、重启容器，均不得访问、递归枚举或自动检测源目录。无后台定时扫描、文件监视器、自动续跑；意外中断后必须手动启动新扫描。
2. **源目录严格只读**：通过 Docker read-only bind mount 挂载，后端只使用只读文件 API，ExifTool 禁止写操作。不得更名、移动、删除、修改原始照片、XMP sidecar 或任何源文件；索引数据库和缓存不放源目录。
3. **完整增量索引**：每次手动扫描遍历目录项确认新增、改动和移除；未变化文件只检查轻量指纹，跳过 EXIF 重提取；只有可确认扫描完整的源才能清理已消失的记录。
4. **兼容广泛**：优先 RAW / JPEG / HEIC/HEIF（另含常见静态照片格式）。容忍文件内容损坏、文件头与后缀不一致、罕见相机 MakerNotes、部分字段缺失；不承诺每个格式都拥有全部 EXIF 字段或可以解码预览。
5. **器材关联可解释**：EXIF 的相机与镜头自动归一化；与 Geargrade 历史设备匹配时保留来源、置信度、可人工覆盖，不因品牌大小写、营销名称或重复购入而误拆。
6. **数据可移植**：历史索引支持结构化、可分片导出，适合其他 Agent / 数据分析工具处理；导出与现有 GGPack 独立、不破坏 v1 导入逻辑。
7. **索引数据与统计分离**：物理文件数、逻辑拍摄数、RAW 数、JPEG 数分别定义，禁止因 RAW+JPEG 双份保存导致照片数翻倍而不标注。
8. **Lightroom 式多列筛选**：默认四列可配置字段、同列多选 OR / 跨列 AND，另提供嵌套 AND/OR/NOT 高级规则；筛选 AST 统一驱动图表、明细、导出及排行榜。
9. **新增拍摄使用量排行榜**：现有排行榜增加第四 Tab，按机身/镜头的逻辑快门次数排序，已售设备与未匹配 EXIF 型号均可统计。
10. **完全排除 GPS**：不提取、保存、筛选、导出位置信息；完整原始标签也须剔除位置相关字段。

## 2. 基于 2026-10-09 用户提供的 Geargrade GGPack

导出格式 geargrade.ggpack.v1。devices 共有 **133** 条器材记录：镜头 64、相机机身 43、运动相机 20、配件 4、无人机 2；wishlist 另有 16 条。相机机身+运动相机的 63 条持有记录，以原始 brand+name 文本去重得到 52 组字符串键，**还未完成语义型号归一化，不能当作 52 个真实不同型号**。

针对实际档案至少验证 Sony A7/A7C/A7M3/A7M4/A7R3/A6400、Fujifilm X100V/X-T5/X-Pro3/X-H1、Olympus E-P7/OM5/E-M5MarkIII、Nikon Z fc、Panasonic S9/GX9、Leica D-Lux7、Ricoh GR IIIx、Pentax Q7，以及 DJI/Insta360/GoPro 静态照片。

已知同型号异名示例：SONY A7C / SONY ILCE-7C；NIKON Z fc / NIKON NIKON Z fc；Fujifilm X100V / Fujifilme X100V (B)。**历史记录中部分用户命名有别名、拼写差异与购买轮次，应通过 alias 处理，而非覆盖原始名称。**

设备清单只有器材档案，无真实拍摄文件样本，不得据此宣称具体 MakerNotes / HEIF 变种已实测通过。对于不支持 RAW 的设备，仅统计其实际可读取的静态照片格式，不虚构 RAW 数据。

## 3. 导航及功能范围

新增顶部“拍摄数据”，保留现有 Dashboard、CList、档案库、排行榜、心愿池、数据工具与设置入口；“设置”新增“拍摄数据源”管理卡片。

- P0：添加/停用只读目录、手动扫描、进度与最近扫描记录、EXIF 索引、消失文件清理、全局概况、基础图表、过滤查询、CSV / JSONL 导出。
- P1：相机/镜头关联、RAW+JPEG 逻辑照片分组、更多交叉统计、Lightroom 式高级筛选与拍摄使用量榜、隐私控制、错误清单与增量扫描报告。
- P2：高级 RAW 标签字段（对焦模式/防抖/快门类型等有则展示）、可选大规模数据分区汇总与分布图扩展。
- 非目标：GPS 或其他位置信息采集/索引/统计/导出、自动监视文件夹、定时扫描、生成并写入 XMP、AI 图片理解、图片上传服务、原片库整理/移动/删除、视频帧级解析、云同步、强制缩略图或图像像素全解码。

## 5. 共同验收原则

- 零自动源读取；只有手动“扫描更新”后可触发 stat/scandir/open/read；实际处理不会写源路径。
- 中断、权限错误、目录不存在、NAS 断线或局部枚举失败绝不错误清除索引。
- 重复扫描结果稳定且跳过未改文件 EXIF；新增、更名、覆盖、删除可被下一次完整扫描正确识别。
- 统计与导出从本地索引数据库读取，不必重新访问原始相片。
- 多列/高级 AST 筛选、图表、导出、排行榜必须共享同一条件与快照；同机型重复购入不得随意归属某台。
- GPS 及其他位置标签在提取/存储/过滤/原始标签/导出全链路排除。
- 原有 GGPack、设备与心愿池、重置等接口兼容，摄影索引有独立生命周期。

规范变更必须同步修订相互关联的字段定义、API Schema、扫描状态机和测试用例，禁止“仅 UI 补逻辑”。
